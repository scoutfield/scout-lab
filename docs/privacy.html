Scout Lab Privacy Policy

Effective August 29, 2026

Scout Lab replaces Chrome's new-tab page with a workspace for discovering public AI code, models, datasets, and research papers.

Data Scout Lab Does Not Collect

Scout Lab does not collect, transmit to the publisher, sell, or share personal information. It has no publisher-operated server, account system, analytics, advertising, or tracking.

Data Stored Locally

Preferences, favorites, hidden-item state, comments, daily notes, cached public-source results, and snapshots stay in the user's browser. The publisher cannot access this information.

Users may explicitly export a backup or choose a local or iCloud Drive folder for Markdown archives. Scout Lab writes only after the user selects the folder and grants browser permission.

Public Source Requests

Scout Lab retrieves public display data from GitHub, Hugging Face, arXiv, and Hacker News (via the Algolia search API). Requests contain only the source filters needed to retrieve selected public results. Favorites, comments, notes, settings, backups, and archives are not sent to these sources.

Data Control And Deletion

Users can clear locally stored Scout Lab data by removing the extension or clearing its site data in Chrome. Users control and may delete exported backup and archive files directly.

Limited Use

Scout Lab's use of information received from APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only for the extension's user-facing AI discovery features.

Changes

Material changes will be published in the Scout Lab repository and reflected in the Chrome Web Store listing before the related release.

Contact

Questions and support requests can be submitted through GitHub Issues.
